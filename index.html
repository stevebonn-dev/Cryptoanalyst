📖 Methodology — What was actually tested

        
The short answer is computed above, not asserted. The referenced setup combines Ichimoku Kinko Hyo cloud (trend / dynamic S-R), a Fibonacci retracement anchored on one swing (static S-R), and a moving-average "bull support band" (cycle trend filter). Because a single annotated chart is a hand-picked sample, this lab rebuilds the setup mechanically and tests it walk-forward across full history.

        
    
          
  • No look-ahead in the honest run: Swing anchors use pivots confirmed R bars later; the running swing low only uses bars up to the decision bar; the cloud plotted at bar i is the span computed displacement bars earlier; higher-timeframe band values come from the last closed bucket.
    • 
          
  • Direction-matched baseline: Every event is compared against all non-event bars in the same cloud regime with the identical ±threshold / horizon resolution rule.
    • 
          
  • Uncertainty & Out-of-Sample: Wilson intervals per level, a block bootstrap (block length 4, 1,500 draws) for the edge versus baseline, and a chronological 60/40 out-of-sample split.
