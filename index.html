📖 What was actually tested — and what this indicator can and cannot do

      
The short answer is computed above, not asserted. The referenced picture combines three separate tools: the Ichimoku Kinko Hyo cloud (trend / dynamic S-R), a Fibonacci retracement anchored on one swing (static S-R), and a moving-average "bull support band" (cycle trend filter). Each is a legitimate, widely used lens. Their combination is a discretionary overlay, and a single annotated chart is a hand-picked sample — it cannot establish reliability. This page therefore rebuilds the setup mechanically and tests it on the full available history.

      
    
        
  • No look-ahead in the honest run. Swing anchors use pivots confirmed R bars later; the running swing low only uses bars up to the decision bar; the cloud plotted at bar i is the span computed displacement bars earlier; higher-timeframe band values come from the last closed bucket. The "chart-style" run deliberately breaks this to quantify hindsight inflation.
    • 
        
  • Direction-matched baseline. Every event is compared against all non-event bars in the same cloud regime with the identical ±threshold / horizon resolution rule, so trend drift and volatility are not mistaken for skill.
    • 
        
  • Conservative resolution. If a single bar could trigger both the adverse and the favourable threshold, it is scored as a loss. Timeouts are reported separately and excluded from the decisive hit rate.
    • 
        
  • Uncertainty is shown, not hidden. Wilson intervals per level, a block bootstrap (block length 4, 1,500 draws) for the edge versus baseline, and a chronological 60/40 out-of-sample split. Overlapping evaluation windows still inflate significance — treat the intervals as optimistic.
    • 
        
  • Known interpretation. "3M bull support band" is implemented as the classic 20-SMA / 21-EMA band computed on quarterly bars and stepped forward; switch the preset if your source means something else. The original screenshot is Bitfinex BTC/USD; this lab uses Binance BTCUSDT (or Bitfinex when reachable) — the levels differ by the exchange basis.
    • 
        
  • What it is good for. Even when the statistical edge is thin, cloud + fib + band confluence is a useful location framework: it defines where to act, where the idea is wrong, and how far a reaction should travel. That is why the export carries a modest weight and an explicit invalidation rather than a stand-alone buy/sell command.
    • 
      

      
Educational analysis of public market data. Nothing here is financial advice, and no indicator — including this one — predicts the future.
